Dataset

Blood Cell Cancer [ALL] 4-class dataset from Kaggle (mehradaria/leukemia). Only the Original folder is used; the Segmented copy is excluded to avoid data leakage.

Split: 70% train (2,279), 15% validation (488), 15% test (489), stratified. Class weights compensate for the smaller Benign class.

Model Pipeline

Two-phase transfer learning on ImageNet-pretrained MobileNetV2.

01

Input

224 x 224 x 3, random flip, rotation and zoom augmentation

02

MobileNetV2 base

Frozen for phase 1, last 40 layers fine-tuned in phase 2 (lr 1e-5)

03

Head

GlobalAveragePooling, Dropout 0.3, Dense softmax (4)

04

Training

Adam, EarlyStopping, ReduceLROnPlateau, class weights
